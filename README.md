# Детектирование заболеваний зерновых растений

Модуль распознавания заболеваний пшеницы по фотографии листа или растения.
Пользователь выбирает снимок, программа определяет состояние растения —
здоровое или одно из четырёх распространённых заболеваний — и показывает
уверенность модели.

Культура: **пшеница** (*Triticum aestivum*). Классы:

| Класс | Название | Возбудитель |
| --- | --- | --- |
| `healthy` | Здоровое растение | — |
| `yellow_rust` | Жёлтая ржавчина | *Puccinia striiformis* |
| `brown_rust` | Бурая ржавчина | *Puccinia triticina* |
| `septoria` | Септориоз листьев | *Zymoseptoria tritici* |
| `mildew` | Мучнистая роса | *Blumeria graminis* |

## Датасет

998 изображений в 5 классах, разбиты на train / val / test как 700 / 149 / 149.
Источник — [Wheat disease images (small dataset)](https://zenodo.org/records/7573133),
DOI [10.5281/zenodo.7573133](https://doi.org/10.5281/zenodo.7573133),
лицензия CC-BY-4.0.

Подробный паспорт набора, включая известные особенности данных, —
в [`docs/DATASET.md`](docs/DATASET.md).

Сами изображения (около 1 ГБ) в репозитории не хранятся и восстанавливаются
скриптом загрузки со сверкой контрольной суммы.

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск приложения

```bash
uvicorn src.app.main:app --reload
```

Открыть <http://127.0.0.1:8000>: выбрать фотографию, нажать «Определить
заболевание» и получить результат: состояние растения, уверенность модели
и вероятности всех пяти классов. Если уверенность ниже 60%, программа
предупреждает об этом и называет второй вариант. Подробности —
в [`docs/stages/stage6.md`](docs/stages/stage6.md).

Запись экрана пользовательского сценария: [`demos/stage2.mp4`](demos/stage2.mp4).

Тесты:

```bash
pytest -q
```

## Модель

Первая модель — MobileNetV3-Small с замороженным backbone, val accuracy 0,705.
Веса: `models/stage4.pt`. Конфиг: `configs/train.yaml`. Подробности —
в [`docs/stages/stage4.md`](docs/stages/stage4.md).

```bash
python -m src.model.train
python -m src.model.predict путь/к/снимку.png
```

Та же модель работает в веб-приложении. Тестовая выборка на этапе 4
не использовалась.

## Качество модели

Исходное качество первой модели на фиксированном `test.csv` (149 снимков):

| Метрика | Значение |
| --- | --- |
| Accuracy | 0,711 (95% ДИ 0,638–0,785) |
| Macro precision / recall / F1 | 0,719 / 0,698 / 0,692 |
| mAP | 0,778 |
| Доля снимков, неверно учтённых в подсчёте по классам | 0,154 |

Метрики по классам, матрица ошибок и кривые precision–recall —
в [`docs/stages/stage5.md`](docs/stages/stage5.md).

```bash
python -m src.model.evaluate
```

## Подготовка данных

```bash
python -m src.data.download    # скачать архив с Zenodo, сверить md5, распаковать
python -m src.data.inventory   # проверить классы и целостность изображений
python -m src.data.dedup       # удалить дубликаты, разметить группы сцен
python -m src.data.split       # разбить на train / val / test
python -m src.data.preview     # собрать контактные листы и HTML-отчёт
```

Визуальная проверка набора — откройте `reports/stage3/dataset_review.html`
в браузере: там сетки миниатюр по классам с подписями выборок, счётчики
и список удалённых дубликатов.
