# Как запустить прототип

Команды ниже выполняются из корня репозитория на ветке `main`. Один интерфейс — веб-страница. Командная строка вызывает ту же модель.

## Зависимости и запуск

Нужен Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn src.app.main:app --reload
```

Откройте http://127.0.0.1:8000. Выберите культуру, загрузите фотографию листа и нажмите «Определить заболевание».

Проверка, что сервер жив и веса на месте: http://127.0.0.1:8000/health.

Тот же снимок из терминала:

```bash
python -m src.model.predict путь/к/снимку.jpg
python -m src.model.predict путь/к/снимку.jpg --crop barley
python -m src.model.predict путь/к/снимку.jpg --crop maize
```

Тесты кода, без датасета:

```bash
pytest -q
```

Для запуска страницы скачивать датасет не нужно: веса уже в `models/`.

## Веса

Сайт берёт файл по выбранной культуре.

| Культура | Файл | Классы |
| --- | --- | --- |
| Пшеница | `models/stage4.pt` | healthy, yellow_rust, brown_rust, septoria, mildew |
| Ячмень | `models/barley.pt` | healthy, brown_rust, ramularia |
| Кукуруза | `models/maize.pt` | healthy, blight, gray_spot, fall_armyworm |

`models/stage10.pt` — вторая пшеничная модель с этапа 10. На тесте того же архива у неё accuracy 0,819. Сайт её не использует: страница отвечает `models/stage4.pt`.

`models/crop_gate.pt` — проверка, что на снимке не чужой объект. Болезнь после неё не называется, если кадр уверенно не похож на лист выбранной культуры.

Сеть везде MobileNetV3-Small. Снимок переводится в RGB, уменьшается, обрезается по центру до 224×224 и нормализуется как ImageNet.

## Конфигурации

Все файлы лежат в `configs/`.

| Файл | Зачем |
| --- | --- |
| `dataset.yaml` | пшеница: источник Zenodo 10.5281/zenodo.7573133, классы, симптомы, разбиение 70/15/15, seed 42 |
| `dataset_barley.yaml` | ячмень, Mendeley 10.17632/4ny92p2r8f.1 |
| `dataset_maize.yaml` | кукуруза, Mendeley 10.17632/3myfctrgk3.1 |
| `train.yaml` | обучение `models/stage4.pt`: backbone заморожен, 10 эпох |
| `train_stage10.yaml` | обучение `models/stage10.pt`: backbone обучается, выбор по val macro F1 |
| `train_barley.yaml` | обучение ячменя |
| `train_maize.yaml` | обучение кукурузы |
| `control.yaml` | контрольные списки этапа 7 |

Пороги страницы заданы в `src/app/settings.py`, не в yaml: файл до 20 МБ, не больше 50 мегапикселей, меньшая сторона от 64 px, средняя яркость 40–220, резкость (дисперсия Лапласиана на превью 224 px) от 40. Уверенный ответ — от 60%. От 40% до 60% — низкая уверенность и второй вариант. Ниже 40% класс болезни не называется.

## Тестовые данные

Списки пшеницы уже в репозитории:

- `data/processed/splits/train.csv`, `val.csv`, `test.csv` — 700 / 149 / 149
- `data/control/*.csv` — контрольные наборы по классам

Сами кадры в git не входят (`data/raw/` в `.gitignore`, архив около 1 ГБ). Их восстанавливает:

```bash
python -m src.data.download
```

После этого тестовый прогон пшеницы:

```bash
python -m src.model.evaluate --weights models/stage4.pt --split test --out-dir reports/stage5
```

Независимый список из 44 снимков: `data/independent/wheat.csv`. Файлы jpeg в git не кладутся. Повторный прогон возможен только если эти файлы лежат по путям из CSV.

```bash
python -m src.model.evaluate \
  --weights models/stage4.pt \
  --split-csv data/independent/wheat.csv \
  --out-dir reports/stage14
```

## Ошибки, которые видит пользователь

Плохой файл не доходит до модели болезни. Страница пишет причину:

- пустой файл или размер больше 20 МБ;
- формат не из JPEG, PNG, BMP, TIFF, WEBP;
- снимок не читается, слишком большой, сторона короче 64 px;
- слишком тёмный, слишком светлый или размытый кадр;
- на снимке не выбранная культура: «На снимке не пшеница. Это не лист пшеницы, поэтому болезнь не определяется. Загрузите фотографию выбранной культуры.» Для ячменя и кукурузы текст тот же, с названием выбранной культуры. Чем является чужой объект, программа не пишет.

Если веса болезни или проверки культуры не найдены, страница отвечает, что сервис недоступен. Сбой записи истории не отменяет уже показанный диагноз.
